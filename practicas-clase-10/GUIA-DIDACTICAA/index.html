Tabla comparativa de sistemas de color en CSS

Sistema Ejemplo CSS Definición Cuándo usarlo
HEX #ff5733 Código hexadecimal que representa valores de rojo, verde y azul. Colores fijos y precisos, paletas estáticas.
RGB rgb(57, 152, 219) Define el color con valores de rojo, verde y azul (0–255). Manipulación dinámica, gradientes, mezcla de luz.
HSL hsl(0, 50%, 30%) Usa matiz (Hue), saturación y luminosidad. Variaciones intuitivas de color, sistemas de diseño.
RGBA rgba(231, 76, 60, 0.5) Igual que RGB pero con canal Alpha (transparencia). Overlays, efectos de transparencia, capas visuales.
